# 追加アート02：猫種としぐさ

18場面の追加素材です。本体の45場面にはまだ含まれていません。ゲーム本体は変更せず、Claudeが取り込める形で用意しています。

- `core/`：三色＋紙色、512pxの原画
- `finish/`：場面に合わせた完成背景、384pxのWebP
- `catalog.json`：作品名・猫種・ファイル名・動きの中心

長毛・短毛、顔・耳・脚の違いに加え、横向き、伸び、仰向け、あくび、開いた目を増やしています。背景に猫や人物は描いていません。

## 本体へ取り込む手順

1. coreのPNGを `art/`、finishのWebPを `art/finish/` にコピーする。
2. このcatalogの項目を、本体の `art/catalog.json` 末尾へ追加する。
3. 猫の位置を見て `motion` の座標を調整する。初期値は目安。
4. `node scripts/build-art.cjs --embed` を実行する。
5. 全作品の描画、猫の動き、スマホ画面を確認する。作品数を固定値で確認しているテストは63場面へ更新する。

本体の三色の猫・小物を完成時にも使い、背景を後ろに加えます。中央を覆うマスクや、背景全体を揺らす演出は入れません。

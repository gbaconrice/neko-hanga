# 三色の絵本アートを追加する

## 制作ルール

柔らかい切り絵・絵本調の猫。写実的な毛並み、3D、クリップアート風の単純図形は避けます。
紙の生成りを余白・猫の白い体として使い、サーモン・ティール・マスタードの3版で全てを描きます。目・口・輪郭もこの3版に含め、4版目を足しません。
図鑑用の番号や文字、枠、UIを原画に入れません。

初回の18場面は画像生成ツールで制作した2枚の3×3アトラスから作成しました。
各タイル境界の3pxを除き、512pxへ正規化、3色＋紙色へ最近傍減色しています。元の生成画像は変更せず、ゲーム用PNGを別途出力しています。

## 更新手順

1. 3×3で9場面の原画アトラスを作ります。9個の正方形を等間隔で配置し、溝・文字・枠なし。各場面の内側には安全な余白を持たせます。
2. `node scripts/build-art.cjs --import /path/to/atlas.png 0` で最初の9場面を、末尾を `9` にして次の9場面を取り込みます。sharpが必要です。
3. 個別PNGを変更した場合は `node scripts/build-art.cjs --embed` でHTML埋め込みを再生成します。
4. 19場面目以降を足すときは、`index.html` の `W` と `scripts/build-art.cjs` の `files` に同じ順で追加し、4色のPNGを置いて `--embed` してください。9場面単位で増やす場合は、追加アトラスを `--import /path/to/atlas.png 18` のように先頭インデックスを指定して取り込めます。
5. ブラウザで試し刷り・完成図・特色・反転を確認します。トンボとアートは同じ変換で動きます。完成図を別画像で後付けする方式ではありません。

画像を増やしても操作する版は3枚。ゲーム実行中は画像を3枚のマスクに分け、色を置き換えて特色を表現します。予告として見せるのはアート周辺部だけで、成功時には同じ版の全体を描画します。

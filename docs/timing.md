# 制限時間と判定の締め切り

後半の紙は「最速で操作しても、めろめろの時間内に終わらない」状態になっていました。
そこで、紙ごとの作業量(つまみの数・目盛り数・連動)から「最速で合わせたときの秒数」を見積もり、
それを基準に制限時間と判定の締め切りを決めるように変えました。

## 最速の操作の見積もり(index.html の定数)

| 定数 | 値 | 意味 |
|---|---|---|
| OP_LOOK | 1.2秒 | 紙を見て、どこがずれているか把握する |
| OP_KNOB | 横・縦 0.9秒 / 回転 1.3秒 / 大きさ 1.5秒 | つまみ1つに手を伸ばし、合ったか確かめる。回転と大きさは見極めにくいので長め |
| OP_STEP | 0.15秒 | 1目盛り動かすごと |
| OP_LINK | 1.5秒 | 連動で別の版が動いた分を合わせ直す(連動1つごと) |
| OP_PRINT | 0.4秒 | 刷るボタンを押す |

最速 = OP_LOOK + Σ(つまみの時間 + 目盛り数×OP_STEP) + 連動の数×OP_LINK + OP_PRINT

## 決め方

- 制限時間 = max(従来の制限時間, TIME_FIT×最速 + 4秒) + 持ち越し。TIME_FIT は刷った枚数が35枚になるまで3倍、そこから少しずつ下げ、60枚で2.2倍(以降そのまま)。
- めろめろの締め切り(紙を出してからの経過秒) = max(制限時間の20%, 1.3×最速 + 0.5秒)
- うっとりの締め切り = max(制限時間の45%, 2.0×最速 + 1.0秒)
- 広げるのは回転つまみが出る段階(7枚刷ったあと、8枚目の紙から)。それより前は従来の割合でも最速で届くので、そのまま(序盤はやさしくしない)。
- ラストチャンスは従来どおり(5秒、20%・45%)。
- 得点の式(残り時間の割合)は変えていません。
- 時間の棒の2本の線は、その紙の実際の締め切りの位置に出ます(前は50%・70%で、判定の80%・55%とずれていた)。

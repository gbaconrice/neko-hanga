# 相棒の猫の受け入れ

これは実装ではありません。素材の取り決めと、組み込むときの確認表です。

相棒の猫には、別の場所に非公開の統合候補（v3.1）があります。**このリポジトリで新しく作り直さず、その候補を組み込みます。** 組み込む人は、先に候補の中身を読み、下の取り決めと食い違う所を一覧にしてから始めてください。

## 1. 決まっている仕様（ユーザー決定）

| 項目 | 決定 |
|---|---|
| 猫の種類 | 10種。ゲームを始めるときに選ぶ |
| 選び直し | 1回のゲームごとには選び直さない。ページを開いている間は同じ猫のまま |
| 保存 | しない。`localStorage` も使わない。ページを閉じたら次は選び直し |
| ライフ | 24px相当の肉球。色は猫ごと |
| 成功判子の言葉 | 「ごろごろ」「うっとり」「めろめろ」 |
| 成功判子の色 | 段階ごとの共通色。猫ごとには変えない |
| 成功判子の形 | 肉球マークの中に文字。判子は約66px、文字は約12px |
| 成功判子の枠 | 丸や四角の枠は付けない |
| 段階の差 | 大きさだけで差を付ける案は却下 |
| 音のボタン | 右上、得点のすぐ隣に小さな音のアイコン |

いまの main との違い：ライフは単色の肉球（24×26px、`.paw`）、成功判子はCSSの文字と丸（`judge()`、`.judge.g0〜g2`）、音のボタンは文字の「音 ON」（88×38px、`#mute`）です。

## 3. 素材の取り決め

### ファイル名

`art/companion/` に置く想定です。番号は `01`〜`10`。

| 素材 | ファイル名の例 |
|---|---|
| 相棒の猫（状態ごとのスプライト） | `cat01-idle@2x.webp`、`cat01-happy@2x.webp` |
| ライフの肉球 | `paw01@2x.png` |
| 成功判子（段階ごと、猫に依らない） | `stamp-g0@2x.png`、`stamp-g1@2x.png`、`stamp-g2@2x.png` |
| 音のアイコン | `sound-on@2x.png`、`sound-off@2x.png` |

状態名は英小文字で固定します：`idle`（ふつう）、`happy`（喜ぶ）、`sad`（しょんぼり）、`dance`（踊る）、`hurry`（あわてる）。

### 大きさ

画面に40pxで出す部品は、端末の画素密度に合わせて3通り用意します。

| 倍率 | 1コマの大きさ | 付ける名前 |
|---|---|---|
| 1倍 | 40px | `@1x` |
| 2倍 | 80px | `@2x` |
| 3倍 | 120px | `@3x` |

| 素材 | 画面での大きさ | 用意する大きさ |
|---|---|---|
| 相棒の猫（HUD） | 40px | 40／80／120px |
| ライフの肉球 | 24px | 24／48／72px |
| 成功判子 | 約66px | 66／132／198px |
| 音のアイコン | 20〜24px | 24／48／72px |

### 形式

- 透過のPNGかWebP。背景を塗らない。
- 状態ごとのスプライトは、正方形のコマを横一列に並べる。コマの間に余白を入れない。
- 1つの状態の中では、コマの大きさと猫の位置（足元の高さ）をそろえる。
- 色数の制限はない。ただし三色の版画の世界観に合わせる。

### コマ数

| 状態 | コマ数 |
|---|---|
| ふつう `idle` | 2〜4 |
| 喜ぶ `happy` | 3〜4 |
| しょんぼり `sad` | 2〜3 |
| 踊る `dance` | 4 |
| あわてる `hurry` | 2〜3 |

### 小さい大きさでの見やすさ

1倍の大きさで、実際の背景の上に置いて確かめます。

- プレイ画面の背景は濃い緑（`--bg` `#243c3a`）。つまみの中心や時間バーの区切りは `#23262d`。この上で輪郭が消えないこと。
- 黒猫：40pxで目と顔の向きが読めること。輪郭が背景に溶けないこと。
- 白や薄い色の猫：薄い輪郭線が、濃い背景の上で細く途切れて見えないこと。
- ライフの肉球：24pxで10色が互いに見分けられること。減ったときの表示（いまは薄くする）でも分かること。
- 成功判子：66pxで、肉球の中の12pxの文字が読めること。紙（`#f5efde`）の上でも読めること。
- 確認には、1倍の画像を背景色の上に並べた一覧を作り、ユーザーに見てもらう。

### 足すテスト

- 猫を選ぶと、ライフの肉球がその猫の色になる。
- 再挑戦しても猫が同じ。選ぶ画面が出ない。
- 3段階の判子の色が、どの猫でも同じ。
- ゲームの間、`localStorage` などに何も書かない（書き込みを見張る）。
- 猫を選ぶボタンの2度押しが、次の画面のボタンに当たらない（`tests/qa.cjs` に足す）。
- 得点の送信が1プレイ1回のまま。
- 画像が外部から読まれない。

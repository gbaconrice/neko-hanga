## PR #13：連打・操作の中断・復帰の点検

320×568・390×844のタッチ操作で調べ、再現した不具合だけを直した。

- 連打が次の画面のボタンに当たる（始まってすぐ肉球が減る、結果を見ないまま次へ進む、など）→ 画面や紙が替わった直後の0.4秒は受け付けない（`TAP_GUARD_MS`）。
- つまみを持ったまま別の指で刷ると、版が薄いまま残った → 操作が切れたら戻す。
- 1つのつまみに2本の指が乗ると目盛りが飛んだ → あとから触れた指だけを追う。
- 再現しなかったもの：周回後のタイマーや表示の取り残し、得点の二重送信、音のオン／オフの喪失。
- 残したもの：2本の指で別々のつまみを持つと、薄くする表示が片方のぶんだけ（見た目だけ）。
- テスト：`tests/qa.cjs`。

## PR #14：説明・結果の読み取りやすさ

320×568・360×640・390×844で実測し、再現した表示の不具合だけを直した。

- 絵本の説明欄で枚数・得点が1文字ずつ折り返した → 折り返さない。見どころは入らなければ「…」で省く。
- 加点の知らせが画面外へはみ出した → 項目の切れ目で折り返す。
- 注文の進み具合が遅れて出た（注文はのちに PR #15 で外した）。
- 復活した紙にラストチャンスの案内が残った → 消す。
- ベストと同点で「ベストまであと0点」 → 出さない。
- `tests/touch.cjs` は、画面が替わった直後の待ちが明けてからつまみを操作するようにした。
- テスト：`tests/ux.cjs`。

## PR #15：注文とむだなしを外す

- 注文・むだなしをすべて外した（加点、札、集計の行、絵本の見どころ）。
- おたすけは注文達成でしか増えなかったので、5枚刷るごとに1つ増えるように（`HELP_EVERY`）。最初1つ・上限3つは同じ。
- ★特色の出る割合と区分は変えていない。注文が出ている間だけ出やすくしていた処理は、注文と一緒になくなった。
- 後半の制限時間の下限を上げた（ユーザー：「拡大縮小のつまみが出るあたりから難しい」）。この部分は別作業でさらに調整中。現行の値は [timing.md](timing.md)。
- 判子の言葉を「ごろごろ・うっとり・めろめろ」に（条件と加点は同じ）。
- 加点の札で、数字が飛んだあとに上半分が空白のまま残った → 詰める。
- CI：追加部品を取得できないときは、ブラウザだけ入れてテストを続ける。

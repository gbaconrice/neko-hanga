# 現行仕様

この文書が、いまのゲームの規則と数値の正本です。経緯は [history.md](history.md) にあります。

- 数値は `index.html` の設定（スクリプト冒頭の「調整用の設定」と `cfg()`）と照合しました（main 027575c 時点）。
- 数値を変えたら、この文書も同じプルリクエストで直してください。
- 「定数」の列はコード上の名前です。

## 1. 1回のゲームの流れ

1. タイトル → 「はじめる」。
2. 紙が1枚出る。つまみで三色の版を動かし、四すみの＋印を重ねて「刷る」。
3. 合っていれば刷り上がり（ローラー → 完成図 → 猫が動く）。ずれていれば、その刷りを丸めて捨て、肉球が1つ減る。
4. 肉球がなくなると、1回だけラストチャンス。失敗すると結果画面（絵本）。
5. 「もう一度あそぶ」または「タイトルへ」。

保存データはありません（図鑑なし、`localStorage` なし）。前回の点とベストは、ページを開いている間だけ覚えます（`sessionBest`、`lastRunScore`）。

## 2. 版とつまみ

| 項目 | 値 | 定数 |
|---|---|---|
| 色 | サーモン `#d78479`・ティール `#3b6863`・マスタード `#c4a052`、紙 `#f5efde` | `INKS`、`PAPER` |
| つまみ1目盛りの角度 | 30度 | `STEP` |
| つまみの可動範囲 | ±12目盛り | `VMAX` |
| 難易度 | 刷れた枚数で段階が上がる（下の表） | `cfg(n)` |

`cfg(n)` の段階（n＝それまでに刷れた枚数）。

| 枚目 | 段階 `tier` | 動く版 | 回転 | 拡大縮小 | 連動 |
|---|---|---|---|---|---|
| 1〜3 | 0 | 1 | 0 | 0 | 0 |
| 4〜7 | 1 | 2 | 0 | 0 | 0 |
| 8〜12 | 2 | 2 | 1 | 0 | 0 |
| 13〜18 | 3 | 2 | 2 | 0 | 1 |
| 19〜25 | 4 | 2 | 1 | 1 | 2 |
| 26〜 | 5 | 2 | 1 | 1 | 3から6枚ごとに+1、最大5 |

つまみの数は「動く版×2＋回転＋拡大縮小」。13枚目から6つになります。

- つまみを押している間は、動かない版を薄くします（`FOCUS_DIM`）。
- 版が1枚合うたびに、トンボの輪・音・つまみの縁で知らせます。全部そろうと紙のふちが白く光り、短い音が鳴ります。
- 「刷る」ボタンは光らせません。自動では合わせません。
- 速く回して離すと、勢いで回って目盛りに止まります（`SPIN_MIN`・`SPIN_MAX`・`SPIN_TAU`）。指を止めてから離すと勢いは付きません。
- つまみの音は、合う位置に近づくほど高くなります（`sTick(d)`）。
- 1つのつまみに2本の指が乗ったら、あとから触れた指だけを追います。

## 3. 制限時間と判定

制限時間と判定の猶予は docs/timing.md を参照（後半の調整を別作業で変更中）。

関係する名前：`sheetTime()`、`cfg()` の `time`・`min`、`TIME_START`・`TIME_STEP`・`TIME_MIN`、`GRADES` のしきい値、時間バーの区切り（`.bar::before`・`.bar::after`）。

時間に関わる、変更中でないもの：

| 項目 | 値 | 定数 |
|---|---|---|
| 残り時間の警告 | 残り5秒から時間バーが点滅し、1秒ごとに音 | `LOW_TIME` |
| 最初の一枚 | つまみに触れるまで時間が減らない。ページを開いて最初のゲームだけ | `waitTouch`、`firstPlay` |
| 時間の持ち越し | 刷ったときの残り時間の35%、最大6秒を次の紙に足す。ミス・時間切れで消える | `CARRY_RATE`、`CARRY_MAX` |

判子の言葉は、残り時間が多い順に「めろめろ」「うっとり」「ごろごろ」です（`GRADES`）。紙の右上に判子が出て、音も段階で変わります。

## 4. ライフ・ラストチャンス

| 項目 | 値 | 定数 |
|---|---|---|
| ライフ | 肉球3つ | `LIVES` |
| 減る条件 | ずれたまま刷る、時間切れ | — |
| 回復 | 5枚連続で刷るたびに1つ（上限3） | `HEAL_EVERY` |
| ラストチャンス | 肉球がなくなったとき1回だけ。1色・回転なしの紙を5秒以内に刷れたら肉球1つで続行 | `LAST_TIME`、`startLast()` |
| ラストチャンスの予告 | 1.1秒 | `LAST_BANNER_MS` |

肉球が残り1つのとき、肉球が脈打ちます。

## 5. 得点

1枚の得点：

```
(BASE_PT + tier×TIER_PT + round(TIME_PT×残り時間の割合)) × 連続倍率
  + ★特色なら SP_PT + 記念の枚なら MILESTONE_PT
フィーバー中は、これ全体に FEVER_MULT を掛ける
```

| 項目 | 値 | 定数 |
|---|---|---|
| きほん | 100点 | `BASE_PT` |
| 段階ごとの加点 | 20点×段階 | `TIER_PT` |
| はやさ | 最大100点（残り時間の割合） | `TIME_PT` |
| 連続倍率 | 1枚ごとに+0.1、上限×1.5 | `MULT_STEP`、`MULT_MAX` |
| ★特色 | +200点 | `SP_PT` |
| 記念 | 10枚ごとに+300点 | `MILESTONE`、`MILESTONE_PT` |
| フィーバー | 5枚続けて刷るとたまり、次の3枚が2倍 | `FEVER_NEED`、`FEVER_SHEETS`、`FEVER_MULT` |

- 倍率が×1.3以上で紙のふちが光り、上限で強く光ります（`hot1`・`hot2`）。
- フィーバーはミスで終わります。紙のふちとローラーが虹色になり、オルゴールが速くなります。
- 取り返し（`comeback`）：2連続以上のあとでミス・時間切れになり、次の1枚を「うっとり」以上で刷ると、連続数が元に戻ります。フィーバーのゲージは戻りません。
- 「注文」と「むだなし」の加点はありません。
- 集計の内訳は、きほん・はやさ・連続・★特色・記念・フィーバーの6つ（`TALLY_NAMES`）。合計は必ず得点と一致します。

## 8. 称号

刷れた枚数で決まります（`RANKS`）。

| 枚数 | 0 | 3 | 7 | 12 | 18 | 25 | 35 |
|---|---|---|---|---|---|---|---|
| 称号 | 見習い | 印刷工 | 刷り師 | 職人 | 親方 | 名人 | 人間国宝 |

肉球の下に「○○まで N枚」、届いた紙で「○○に昇格！」。フィーバー中はこの欄に「×2 残りN枚」を出します。

## 9. 刷り上がりと完成演出

| 項目 | 値 | 定数 |
|---|---|---|
| ローラーが紙を横切る時間 | 0.42秒 | `ROLL_MS` |
| 完成図の表示 | 約2秒（2,050ミリ秒） | `REVEAL_MS` |
| タップで送れるまで | 0.6秒 | `SKIP_AFTER_MS` |
| 猫のコマの時間 | 6コマ、計1,080ミリ秒 | `FRAME_TIMES`、`ANIMATION_DURATION` |

- 刷るとローラーが左から右へ通り、通った所から完成図に替わります。
- 完成すると背景が加わり、猫だけが動きます（前脚・しっぽ・胴体・表情）。背景と小物は動きません。画像を揺らす処理や頭のメッシュ変形は使いません。
- ずれた紙・時間切れの紙は丸めて捨てます（`crumple()`）。
- ずれたとき、1目盛りだけなら「あと1目盛り！」、全部1目盛り以内なら「おしい！ あと少し」。
- インクが乗る瞬間に画面がわずかに揺れ、加点の数字がスコアへ飛びます。
- 動きを減らす端末設定では、最初のコマを表示します。
- 画像のデコードは同時に4作品まで。プレイ中の読み込みではタイマーを止めます。

## 10. 結果画面

- 刷った絵が1枚ずつ落ちて重なり（最大16枚、`STACK_MAX`）、絵本になります。刷った瞬間に96pxの控えを取ります（`va.thumb`）。
- 集計は1行ずつ（1行0.42秒、`TALLY_STEP_MS`）。得点のあたりをタップで飛ばせます。
- 集計のあとに前回との比較（「前回より +N点」「ベストまであとN点」「ベスト更新！」）。同点のときは「あと0点」を出しません。
- 絵本は1作品1ページ。ページに作品名・ページ数・加点・見どころ。いちばん高得点の1枚に「いちばんの一枚」。
- 作品がない回は「完成した絵はありません」。

## 11. 連打・操作の保護（PR #13）

| 項目 | 値 | 定数 |
|---|---|---|
| 受け付けない時間 | 画面や紙が替わった直後の0.4秒 | `TAP_GUARD_MS` |
| 対象 | 「刷る」「おたすけ」「はじめる」「もう一度あそぶ」「タイトルへ」 | `tapHeld()` |
| 延長 | その間に押されたら、待ち時間を延ばす | `tapHold()` |
| つまみ | 画面が替わった直後だけ受け付けない。紙が替わった直後はすぐ回せる | `screenUntil` |
| 対象外 | 完成図の早送り | — |

- つまみの操作が切れたら（別の指で刷った、`pointercancel` など）、薄さを戻して目盛りへ戻します。
- テストでは `window.__pz.tapGuard(0)` で切れます（`?debug=1` のときだけ）。

## 12. 音

| 項目 | 値 | 定数 |
|---|---|---|
| 鳴き声 | 録音1種類（`sounds/cat-soft.mp3`）を、高さ0.9・1・1.12の3通りで | `CAT_AUDIO`、`VOICE_RATES` |
| オルゴール | 合成。プレイ中だけ鳴る。連続3回で旋律、6回で飾りの音 | `MUSIC_VOL`、`MB_*` |
| 連続成功のチャイム | 連続するたびに音階が上がる | `SCALE` |

- 音声は埋め込んだMP3を直接デコードします。読み込みに `fetch` を使いません。
- 音ボタンで止めると、BGMも鳴き声も鳴りません。結果画面とタイトルでは BGM を鳴らしません。
- 絵本の絵をタップしても鳴きません。

## 13. GRAVITY連携

| 項目 | 値 | 定数・場所 |
|---|---|---|
| SDK | AgentSDK 1.0.2。プロフィール取得は4秒で打ち切り | `SDK_TIMEOUT` |
| ランキング | 1つだけ（日替わりなどの分割はできない） | — |
| 得点の送信 | `window.parent.postMessage({type:'gameOver',score}, '*')` | `sendScore()` |
| 上部余白 | 埋め込み時、高さ812px以上で98px、それ未満で74px。単体では0px。`?top=数値` で上書き | `topInset()` |
| 動作確認の画面 | 題字を5回続けてタップ、または `?check=1` | `openCheck()` |

得点の送信は、ゲーム終了時に1回です。途中で閉じたとき（`pagehide`）はその時点の得点を送り、その後の終了時はより高いときだけ送り直します。

動作確認の画面は、`localStorage` が使えるかを書いてすぐ消して調べます。ゲームのデータは保存しません。

確認用（`?debug=1` のときだけ）：`window.__pz.state()`、`tapGuard(0)`（連打の保護を切る）、`setLives(n)`（ラストチャンスを使用済みにする。試すときは `setLives(n,true)`）、`forceSp(k)`、`rareOff(true)`。

## 14. 画面の言葉

文言を変えたら、フォントを作り直します（`python3 scripts/build-font.py`）。

- タイトルの説明3行：「つまみを回すと、色ごとの版が動きます。」「四すみの＋印がすべて重なったら「刷る」を押してください。」「ずれたまま刷ったり時間が切れたりすると、肉球が1つ減ります。」
- プレイ中の案内（`HINTS`）：最初の一枚、版が2色に増えた、回すつまみ、連動、拡大縮小。

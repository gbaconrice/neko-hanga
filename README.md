# ぴったり印刷所

版のズレを直して作品を刷る、印刷テーマのパズルゲームです。GRAVITY「みんなのAIスタジオ」向けに作っています。

## 遊び方

- 3色の版がズレた状態で出てきます。色つきのボタンを押して、四すみのトンボ（＋印）を重ねます。
- 「刷る」を押してぴったりなら1枚成功。ズレていたり時間切れになるとライフが1減ります。
- ライフは3つ。尽きたときの刷れた枚数がスコアです。

## 構成

- `index.html` … ゲーム本体（HTML・CSS・JavaScriptを1ファイルにまとめています）
- 絵柄は画像ファイルではなく、コード内の図形データ（`W`）から描いています。1行足すと絵柄が1つ増えます。
- 同じ絵柄でも、配色・色の入れ替え・塗りの質感（ベタ／網点／斜線）・地模様・紙の色・左右反転が毎回変わります。
- 難しさ・制限時間・ライフ数は、スクリプト冒頭の設定と `cfg()` で調整できます。

## GRAVITY連携

- AgentSDK 1.0.2 を読み込み、名前が取れたらタイトルに表示します（4秒応答がなければ出さずに進みます）。
- ゲーム終了時に1回だけ `window.parent.postMessage({ type: 'gameOver', score }, '*')` を送ります。
- 上部余白は暫定値（画面高812px以上で98px、それ未満で74px）です。`?top=数値` で上書きできます。
- 上部余白・ランキングの受理・プロフィール取得・音は、GRAVITY実機での確認がまだです。

## 動作確認用のURLパラメータ

- `?gallery=1` … 全絵柄を図鑑で表示
- `?top=数値` … 上部余白を指定
- `?debug=1` … 自動テスト用に内部状態を参照できるようにする

# ぴったり印刷所

版のズレを直して猫の版画を刷る、印刷テーマのパズルゲームです。GRAVITY「みんなのAIスタジオ」向けに作っています。

## 遊び方

- 3色の版がズレた状態で出てきます。色つきのつまみを指で回して、四すみのトンボ（＋印）を重ねます。つまみの左右をタップしても1目盛り動きます。
- 「刷る」を押してぴったりなら成功。ズレていたり時間切れになるとライフが1減ります。
- ライフは3つ。尽きたときの合計得点がスコアで、ランキングにはこの得点を送ります。
- 5枚連続で成功するとライフが1つ回復します。
- 枚数が進むと、動く版が増え、回転・連動・拡大縮小のつまみが順に登場します。
- 刷り上がると猫が鳴きます（鳴き声は録音ではなく、ブラウザ内で合成した音です）。
- たまに「★特色刷り」（金・藍・蛍光・墨・夕焼け）が出ます。図鑑で絵柄ごとに集められます。
- 「注文」（時間を半分以上残して3枚、など）を達成すると、ボーナス点と「おたすけ」がもらえます。
- 「おたすけ」は、ズレているつまみ1つを自動で合わせます。
- 終了時に、刷れた枚数に応じた称号（見習い〜人間国宝）が付きます。

## 得点

1枚の得点 =（基本100 + 難しさの段階×20 + 残り時間の割合×100）× 連続倍率 + ボーナス

- 連続倍率は、連続成功1枚ごとに +0.1（最大 ×2.0）。ミスで ×1.0 に戻ります。
- ボーナスは、特色刷り +200、注文達成 +300。
- 数値はスクリプト冒頭の `BASE_PT` などで調整できます。

## 構成

- `index.html` … ゲーム本体（HTML・CSS・JavaScriptを1ファイルにまとめています）
- 絵柄は画像ファイルではなく、コードで描いた猫です。毛柄19種（`COATS`）× ポーズ7種（`POSES`）で133柄あります。
- 毛柄を `COATS` に1行足すと、ポーズの数だけ絵柄が増えます。模様は、しま・うずまき・斑点・三毛・サビ・ぶち・ハチワレ・くつした・ポイントに対応しています。
- 同じ絵柄でも、質感（ベタ／網点／斜線）・地模様・紙の色・左右反転・表情・小物が毎回変わります。
- 図鑑（刷った枚数・集めた特色）と自己ベストは端末内に保存します。GRAVITY上で残り続ける保証はありません。
- 難しさ・制限時間・ライフ数は、スクリプト冒頭の設定と `cfg()` で調整できます。

## GRAVITY連携

- AgentSDK 1.0.2 を読み込み、名前が取れたらタイトルに表示します（4秒応答がなければ出さずに進みます）。
- ゲーム終了時に1回だけ `window.parent.postMessage({ type: 'gameOver', score }, '*')` を送ります。
- 上部余白は暫定値（画面高812px以上で98px、それ未満で74px）です。`?top=数値` で上書きできます。
- 上部余白・ランキングの受理・プロフィール取得・音は、GRAVITY実機での確認がまだです。

## 動作確認用のURLパラメータ

- `?gallery=1` … 全絵柄を図鑑で表示
- `?top=数値` … 上部余白を指定
- `?debug=1` … 自動テスト用に内部状態を参照できるようにする

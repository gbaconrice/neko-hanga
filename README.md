# ねこ版画

三色の版を合わせて猫の絵を刷る、GRAVITY向けのパズルゲームです。

## 遊び方

つまみを回すか、左右をタップして四すみの＋を重ね、「刷る」を押します。版は3枚。枚数が進むと、回転・連動・拡大縮小のつまみが加わります。

ライフは肉球3つ。ミス・時間切れで減り、5枚連続成功で1つ回復します。残り5秒で時間バーが点滅し、1秒ごとに音が鳴ります。注文達成でボーナス点とおたすけがもらえます。得点・難易度・制限時間はスクリプト冒頭と `cfg()` で調整できます。

## アートと完成演出

45場面を収録。合わせる間も三色の絵全体を表示し、成功すると周囲に花や背景が加わります。元の猫・小物を別の絵に置き換えず、同じ版の上に完成の景色を加える構成です。

調整対象はサーモン・ティール・マスタードの3色。完成後の背景には色を足します。猫の顔や頭の周辺だけを局所的に動かし、背景と紙全体は静止させています。完成図は約2秒表示し、0.6秒たてば紙か「刷る」のタップで次へ送れます。動きを減らす端末設定では猫の動きを止めます。

猫は白猫・茶トラ・ハチワレに加え、三毛、シャム、ロシアンブルー、スコティッシュフォールド、ペルシャ、メインクーン、アメリカンショートヘア、ベンガルを描き分けています。

図鑑・収集データ・自己ベストの永続保存はありません。終了画面には、その回に刷った作品だけを並べます。作品をタップすると大きく表示し、猫が動いて鳴きます。一覧は刷った瞬間の控えを使い、描き直しません。アートの中央を覆うマスクや、プレイ画面の常設説明文もありません。

## 操作と音

つまみ領域だけでタッチの既定動作を止め、高速連打による拡大を抑止します。回す操作と左右タップは維持し、他のボタンや終了画面のスクロールは対象にしません。

鳴き声は効果音ラボ「猫の鳴き声2（甘え声）」。埋め込んだMP3を直接デコードし、音声の読み込みに `fetch` を使いません。最初の操作で音を有効にし、iPhone/iPadではメディア音声を優先します。Web AudioとHTMLAudioで補い合い、再生拒否時は音ボタンから再開できます。出典・規約は [sounds/README.md](sounds/README.md)。

## 構成と開発

`index.html` に全アート・完成用背景・音声を埋め込んでいます。GRAVITYにHTMLだけを渡す場合も、素材サーバーへの接続は不要です。

- `art/catalog.json`：作品名・ファイル名・猫の動く位置
- `art/*.png`：三色＋紙色の原画
- `art/finish/*.webp`：完成時に加わる背景
- `art/shapes/*.png`：白い毛や紙の抜きを保つシルエット
- `scripts/build-art.cjs`：素材の取り込み・HTMLへの埋め込み
- [art/README.md](art/README.md)：追加手順
- [HANDOFF.md](HANDOFF.md)：Claudeへの引き継ぎ

`npm install --no-save sharp playwright` で開発依存を導入し、`python -m http.server 4173` で確認できます。

検証は `node tests/game.cjs`、`node tests/touch.cjs`、`node tests/finish.cjs`、`node tests/polish.cjs`。Chromiumは `CHROMIUM_PATH`、`/usr/bin/chromium`、Playwright付属のものの順で使用します。

## GRAVITY連携

`gravity-entry.html` は約1,700文字の入口です。GitHub Pagesの `index.html` を取得し、iframeを使わずに同じ画面へ展開します。HTMLを小さく渡す必要があるときに使えます。GitHub Pagesの公開と、GRAVITY内から外部取得（`fetch`）ができることが前提で、どちらも実機では未確認です。

AgentSDK 1.0.2。プロフィールは4秒で打ち切り、取得失敗でも遊べます。終了時は1回だけ `window.parent.postMessage({ type: 'gameOver', score }, '*')` を送ります。

埋め込み時の上部余白は暫定値（高さ812px以上98px、それ未満74px）。`?top=数値` で指定できます。通常ブラウザでは0pxです。

`?debug=1` では `window.__pz` に状態を公開します。音声状態・再生回数・エラーも参照できます。GRAVITY実機での余白、ランキング受理、iOS実機の音声は確認が必要です。

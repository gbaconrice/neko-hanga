# ねこ版画

三色の版を合わせて猫の絵を刷る、GRAVITY向けのパズルゲームです。

## 遊び方

つまみを回すか、左右をタップして四すみの＋を重ね、「刷る」を押します。版は3枚。枚数が進むと、回転・連動・拡大縮小のつまみが加わります。

ライフは肉球3つ。ミス・時間切れで減り、5枚連続成功で1つ回復します。残り5秒で時間バーが点滅し、1秒ごとに音が鳴ります。

最初の一枚は、つまみに触れるまで時間が減りません（その回の最初のプレイだけ）。つまみを押している間は、動かない版を少し薄く表示します。連続成功のたびにチャイムの音階が上がり、倍率が×1.5以上で紙のふちが光ります。タイトルの絵は開くたびにちがう作品です（タップでは替わりません）。版が1枚合うたびにトンボの輪と音で知らせ、全部そろうと「刷る」が光ります。自動では合わせません。刷るとインクローラーが紙を横切り、通った所から完成図に替わります。ずれたまま刷った紙や時間切れの紙は、丸めて捨てます。早く刷るほど、残り時間の一部（最大6秒）が次の紙に持ち越されます。プレイ中は合成のオルゴールが流れ、連続成功で音が増えます。注文達成でボーナス点とおたすけがもらえます。得点・難易度・制限時間はスクリプト冒頭と `cfg()` で調整できます。

## アートと完成演出

153場面を収録。合わせる間も三色の絵全体を表示し、完成すると花や景色が加わります。完成用の猫には1場面あたり6枚のポーズを描き起こし、前脚・しっぽ・胴体・表情が変わるアニメーションを再生します。背景と小物は静止し、画像を揺らす処理や頭のメッシュ変形は使いません。

調整対象はサーモン・ティール・マスタードの3色。完成図は約2秒表示し、0.6秒たてば紙か「刷る」のタップで次へ送れます。動きを減らす端末設定では最初のコマを表示します。

猫の品種・毛の長さ・模様・体格・姿勢を描き分け、親子や複数の猫がいる場面も収録しています。今回の追加はバーマン、シャルトリュー、バリニーズ、ヒマラヤン、ラガマフィン、シンガプーラなどの9場面です。

結果画面は、完成した作品を1枚1ページで見られる絵本です。左右ボタン・スワイプ・矢印キーでめくり、絵をタップすると猫の動きをもう一度見られます。作品はその回だけ保持し、図鑑や永続保存はありません。

## 操作と音

つまみ領域だけでタッチの既定動作を止め、高速連打による拡大を抑止します。回す操作と左右タップは維持し、他のボタンや絵本のページ送りも使えます。

鳴き声は効果音ラボ「猫の鳴き声2（甘え声）」。埋め込んだMP3を直接デコードし、音声の読み込みに `fetch` を使いません。最初の操作で音を有効にし、iPhone/iPadではメディア音声を優先します。Web AudioとHTMLAudioで補い合い、再生拒否時は音ボタンから再開できます。出典・規約は [sounds/README.md](sounds/README.md)。

## 構成と開発

`index.html` に全アート・完成用背景・猫の連続コマ・音声を埋め込んでいます。GRAVITYにHTMLだけを渡す場合も、素材サーバーへの接続は不要です。

- `art/catalog.json`：作品名・ファイル名・猫種・姿勢
- `art/*.png`：三色＋紙色の原画
- `art/finish/*.webp`：完成時に加わる背景
- `art/animation/`：連続コマ・制作素材・静止領域の検証用マスク
- `scripts/build-art.cjs`：素材の取り込み・HTMLへの埋め込み
- [art/README.md](art/README.md)：追加手順
- [HANDOFF.md](HANDOFF.md)：Claudeへの引き継ぎ

`npm install --no-save sharp playwright` で開発依存を導入し、`python -m http.server 4173` で確認できます。

アニメーションの再生成手順は [art/animation/README.md](art/animation/README.md)。画像はHTMLに埋め込み、同時にデコードするのは4作品までに抑えます。

文字は丸ゴシック（Zen Maru Gothic、SIL OFL 1.1）を、使う文字だけ切り出して埋め込んでいます。著作権表記とライセンス全文は `fonts/OFL.txt` にあり、`index.html` にも同じ文をコメントとして入れています（詳細は `fonts/README.md`）。文言や作品名を変えたら、素材の埋め込みのあとに `python3 scripts/build-font.py` を実行してください（`pip install fonttools brotli` が必要）。

検証は `node tests/animation.cjs`、`node tests/game.cjs`、`node tests/touch.cjs`、`node tests/finish.cjs`、`node tests/polish.cjs`、`node tests/fun.cjs`。Chromiumは `CHROMIUM_PATH`、`/usr/bin/chromium`、Playwright付属のものの順で使用します。

## GRAVITY連携

`gravity-entry.html` は約1,700文字の入口です。GitHub Pagesの `index.html` を取得し、iframeを使わずに同じ画面へ展開します。HTMLを小さく渡す必要があるときに使えます。GitHub Pagesの公開と、GRAVITY内から外部取得（`fetch`）ができることが前提で、どちらも実機では未確認です。

AgentSDK 1.0.2。プロフィールは4秒で打ち切り、取得失敗でも遊べます。終了時は1回だけ `window.parent.postMessage({ type: 'gameOver', score }, '*')` を送ります。

埋め込み時の上部余白は暫定値（高さ812px以上98px、それ未満74px）。`?top=数値` で指定できます。通常ブラウザでは0pxです。

`?debug=1` では `window.__pz` に状態を公開します。音声状態・再生回数・エラーも参照できます。GRAVITY実機での余白、ランキング受理、iOS実機の音声は確認が必要です。

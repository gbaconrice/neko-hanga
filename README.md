# ぴったり印刷所

三色の版のズレを直して、絵本のような猫の作品を刷るパズルゲーム。GRAVITY「みんなのAIスタジオ」向けです。

## 遊び方

- 色つきのつまみを回し、四すみのトンボ（＋印）を重ねて「刷る」。つまみの左右タップでも1目盛りずつ動きます。
- つまみ領域では、CSSとキャンセル可能なタッチイベントの両方でダブルタップ拡大を抑止します。回す操作・左右タップはPointer Eventsで処理し、他のボタンや終了画面のスクロールには影響させません。
- 調整中に見えるのは、版の周辺の試し刷りだけ。成功すると輪郭・表情を含む完成図が現れ、約1.5秒眺めてから次の紙へ進みます。
- ライフは3つ。ミス・時間切れで1つ減り、5枚連続成功で1つ回復します。
- 枚数が進むと、動く版が増え、回転・連動・拡大縮小が順に登場します。版数は常に3枚です。
- 注文達成でボーナス点と「おたすけ」。おたすけはズレているつまみ1つを合わせます。
- 特色刷りはインク3色の置き換えです。追加の版や操作は増えません。
- 終了画面には、そのプレイで刷った作品と称号が表示されます。図鑑・収集データ・自己ベストの永続保存はありません。

## アート

旧来の手続き描画を全て置き換え、絵本調のオリジナル18場面を収録しました。
通常刷りはサーモン `#d78479`・ティール `#3b6863`・マスタード `#c4a052` の3色と、紙の生成り `#f5efde`。原画をこの4値に減色し、実際に3枚の透過マスクに分けています。輪郭や目もこの3色のいずれかで刷り、隠れた4版目はありません。

`art/*.png` は512px角の4色PNGです。全作品と鳴き声を `index.html` に埋め込んでいるため、GRAVITYにHTMLだけを渡す場合もアート・音源サーバーへの接続は不要です。タイトルは画像読み込み完了まで開始を待ち、失敗時は再読み込みできます。分版キャッシュは3作品までに制限しています。

制作・追加手順は [art/README.md](art/README.md)。枚数をごまかすための単なる色違いではなく、18場面の異なる構図を用意しています。特色と左右反転は別の刷りとして加わります。

## 音

効果音ラボ「猫の鳴き声2（甘え声）」を成功時に再生。約0.76秒、原音の高さで、控えめな音量にしています。音OFFで再生中の鳴き声も止まります。読み込めない環境ではゲームを継続し、印刷の短い効果音のみ鳴ります。出典・利用条件は [sounds/README.md](sounds/README.md)。

## 得点・調整

1枚の得点 =（基本100 + 難しさの段階×20 + 残り時間の割合×100）× 連続倍率 + ボーナス。
連続倍率は成功ごとに+0.1、最大×2.0。ミスでリセット。特色+200、注文+300。
ライフ、時間、得点、難易度は `index.html` のスクリプト冒頭と `cfg()` で調整できます。

## GRAVITY連携

- AgentSDK 1.0.2。プロフィール取得は4秒で打ち切り、失敗しても遊べます。
- ゲーム終了時に1回だけ `window.parent.postMessage({ type: 'gameOver', score }, '*')` を送ります。
- 埋め込み時の上部余白は暫定値（高さ812px以上98px、それ未満74px）。`?top=数値` で指定できます。通常ブラウザでは0pxです。
- 上部余白・ランキング受理・プロフィール・音声はGRAVITY実機での確認が必要です。
- `?debug=1` で開くと、自動検証用の内部状態を `window.__pz` で参照できます。

## ローカル確認

`python -m http.server 4173` を実行して http://localhost:4173 を開きます。
ブラウザ回帰検証は `node tests/game.cjs`、連打・回転のタッチ操作検証は `node tests/touch.cjs`。開発依存は `npm install --no-save sharp playwright` で導入できます。Chromiumは `/usr/bin/chromium`、`CHROMIUM_PATH` 指定、またはPlaywright付属のものを使用します。

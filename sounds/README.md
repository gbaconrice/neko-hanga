# 成功時の猫の鳴き声

成功後は、効果音ラボの異なる録音3種類を順に鳴らしています。異なる猫の個体かどうかは不明です。

- `cat-soft.mp3`：「猫の鳴き声2（甘え声）」。元ファイルのまま。
- `cat-clear.mp3`：「猫の鳴き声1（ニャー）」。音量と余韻を調整。
- `cat-murmur.mp3`：「猫の鳴き声3（ニャウ～ン）」。テンポと音量を調整。

提供元は[効果音ラボ 自然・動物](https://soundeffect-lab.info/sound/animal/)です。[利用規約](https://soundeffect-lab.info/agreement/)と[FAQ](https://soundeffect-lab.info/faq/)を2026-11-18に確認しました。商用利用・ゲーム内での加工利用可。CC0やパブリックドメインではなく、素材単体・素材集としての再配布や音源への直リンクは禁止されています。
このファイルはゲーム内の効果音です。ゲームには埋め込んでおり、外部読み込みや試聴用の単独配信は行いません。完成絵や結果画面の絵をタップしても鳴きません。

再生成する場合は、提供元ページから「猫の鳴き声1」と「猫の鳴き声3」を各自の利用条件で入手し、ローカルでそれぞれ `cat-cry1.mp3` と `cat-cry3.mp3` にします。
`node scripts/make-voice-variants.cjs <元音源のローカルディレクトリ>`（制作時のみ ffmpeg が必要）が元ファイルのハッシュを照合し、加工版2点を生成します。
通常の再ビルドは `node scripts/embed-game.cjs` で、HTMLに入っている録音を維持します。生音源ファイルを追加・差し替えたり、加工版2点をGitで配布したりしません。
